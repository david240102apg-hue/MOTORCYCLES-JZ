Publicar inventario en línea

Así todos los compradores ven el mismo inventario, en cualquier teléfono y con el mismo link, y se actualiza solo cada vez que guardas un cambio. Usa Firebase (gratis). Solo se publican nombre, código, motos, foto, precio de venta y stock.

Cómo configurarlo (una sola vez, ~5 minutos)
  1. Entra a console.firebase.google.com con tu cuenta Google → Agregar proyecto → ponle un nombre → crear (desactiva Analytics).
  2. Menú Compilación → Authentication → Comenzar → Correo/contraseña → activar. Luego pestaña Usuarios → Agregar usuario: crea tu correo y una contraseña (solo tú).
  3. Menú Compilación → Realtime Database → Crear base de datos → modo bloqueado. Copia la dirección que aparece arriba (empieza con https:// y termina en firebaseio.com o firebasedatabase.app).
  4. En la pestaña Reglas pega esto y toca Publicar:
    { "rules": { "catalogo": { ".read": true, ".write": "auth != null" } } }Así todos pueden ver el catálogo, pero solo tú puedes cambiarlo.
  5. Ícono de engranaje → Configuración del proyecto → General → copia la Clave de API web (Web API Key).
  6. Pega abajo la dirección, la clave de API, tu correo y tu contraseña, y toca Guardar y publicar. Después descarga la tienda para compradores una vez y súbela a tu sitio: ya no tendrás que volver a subirla.

Avisos de pedidos en tu celular (ntfy)

Cada vez que un comprador haga un pedido, te llega una notificación al celular, gratis y sin tarjeta.

Cómo activarlo (2 minutos)
  1. En tu Android instala la app ntfy desde Play Store.
  2. Aquí abajo toca Generar tema y luego Guardar. Copia ese tema.
  3. En la app ntfy toca + → pega el tema → Subscribe. Acepta los permisos de notificaciones.
  4. Toca Enviar prueba: debe sonar tu celular.

Instalar como app (publicar el sitio)

Para que aparezca "Instalar app" en Chrome, la página tiene que estar publicada con https. Este botón arma un .zip con todo listo: la tienda para compradores, la app de administrador en una carpeta privada, los íconos y los archivos que exige el navegador.

Cómo publicarlo en Netlify (gratis)
  1. Descarga el .zip y descomprímelo. Te queda una carpeta con index.html y otra carpeta de nombre panel-xxxxxx.
  2. Entra a app.netlify.com/drop (crea cuenta gratis con tu Google) y arrastra la carpeta completa.
  3. Netlify te da un link tipo algo.netlify.app. Ese es el link de tus compradores.
  4. Para entrar tú como administrador, usa ese link + /panel-xxxxxx/ (el nombre exacto está en el mensaje que sale al descargar). Guárdalo y no lo compartas.
  5. En el teléfono, abre cada link en Chrome → menú ⋮ → Instalar app (o "Agregar a la pantalla de inicio").

En el panel nuevo empieza vacío: crea tu clave y usa Ajustes → Restaurar respaldo con tu archivo .json para pasar tus datos. Si cambias el nombre, el logo o la configuración, vuelve a descargar y subir el sitio.

Tienda para compradores

Descarga un archivo aparte para tus clientes: trae el catálogo con precios y stock, pero sin costos, sin finanzas y sin acceso de administrador. Envíaselo por WhatsApp o súbelo a una página web. Cuando cambies precios o stock, descárgalo de nuevo.

Para tu sitio web: sube el archivo de la tienda con el nombre index.html y, junto a él, catalogo.json. Los compradores siempre verán el inventario del catalogo.json más reciente. Cada vez que cambies precios o stock, descarga el catalogo.json nuevo y reemplázalo en tu sitio; el index.html no hay que volver a subirlo. Tu archivo de administrador nunca lo subas al sitio. Guárdalo solo en tu teléfono o computadora.

Respaldo de tus datos

Tus datos se guardan en este navegador. Descarga un respaldo de vez en cuando para no perderlos (por ejemplo si borras los datos del navegador) o para pasarlos a otro dispositivo.
